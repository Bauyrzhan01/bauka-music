Папка для музыки — Bauka Music
=============================

1. Скачайте песни и положите сюда (assets/music/)
   Форматы: .mp3  .m4a  .wav

2. Перезапустите сервер:
   npm start
   (или: npm run music:scan)

Название трека возьмётся из имени файла.
Например: my-favorite-song.mp3 → "My Favorite Song"

Поля заполнять не нужно.
