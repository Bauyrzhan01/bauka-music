Встроенная музыка Tolqyn (источник 1)
=====================================

Сюда вы кладёте треки ПЕРЕД сборкой приложения.
Пользователь скачивает APK — музыка уже внутри, ничего загружать не нужно.

Форматы: .mp3  .m4a  .wav  .aac

После добавления файлов:
  npm run music:scan
  npm run android:usb

Источник 2 — музыка с телефона пользователя («Моя музыка» в приложении).

Обложки и метаданные: веб-админка (npm start) или server/data/tracks-meta.json
